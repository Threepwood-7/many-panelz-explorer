# many-panelz-explorer

Multi-panel, Windows-focused file explorer built with PySide6.

Tooling: this project uses uv + Hatch.

## Setup

```powershell
uv sync --extra dev
```

## Run

```powershell
uv run many-panelz-explorer
```

## Check

```powershell
uv run ruff check .
uv run pytest -q
uv run hatch build
```
